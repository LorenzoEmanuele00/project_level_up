Design system & libreria componenti

Riferimento unico per design e sviluppo Flutter. Ogni componente ha nome, livello atomico, dominio, varianti e stati interattivi. Le anteprime seguono il tema e l'accento scelti nella barra laterale.

Un solo font
Space Mono 400/700 ovunque. La gerarchia nasce da dimensione e peso, non da famiglie diverse.
Blocchi morbidi
Superfici piene, raggi ampi (14–30), pastelli per le statistiche. Bordi solo dove serve separare.
Accento personale
L'utente sceglie l'accento (5 palette). Tutti i token derivati si calcolano da quel colore.
Feedback celebrativo
Ogni azione di gioco (EXP, level up, reward) ha un overlay dedicato con motion a molla.

enum Difficulty { facile, media, difficile }      // → 10 / 20 / 40 EXP
enum Frequency  { daily, x5, x3, x2 }             // volte a settimana
enum HabitHue   { red, blue, teal, green, gold }  // red = accento utente
enum RewardTier { piccola, media, grande }        // → 10 / 25 / 60 RP
enum HeroClass  { guerriero, studioso, monaco, creatore, esploratore }
enum MedalTier  { bronzo, argento, oro }

class Hero {
  final String? name;            // null → "Eroe"
  final AvatarMode avatarMode;   // initial | icon
  final String? avatarIcon;      // chiave icona
  final Color accent;            // una delle 5 palette
  final HeroClass? heroClass;
  final int level, exp, rewardPoints;
  final ThemeMode theme;
}

class Habit {
  final String id, name, icon;
  final Difficulty difficulty;
  final Frequency frequency;
  final HabitHue hue;
  final int streak, totalCompletions;
  final DateTime? lastCompletedAt;
  final bool archived;
  int get exp => const {Difficulty.facile: 10, Difficulty.media: 20, Difficulty.difficile: 40}[difficulty]!;
  bool isDueOn(DateTime d) { /* calendario per frequency */ }
  bool isDoneOn(DateTime d) => lastCompletedAt != null && DateUtils.isSameDay(lastCompletedAt, d);
}

class Reward { final String id, name; final String? note; final RewardTier tier;
  int get cost => const {RewardTier.piccola: 10, RewardTier.media: 25, RewardTier.grande: 60}[tier]!; }

class Redemption { final String id, rewardName; final int cost, levelAt; final DateTime at; }

class Completion { final String habitId; final DateTime at; final int exp; } // storico per grafici
